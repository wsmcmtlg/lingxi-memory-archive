## 3. 已知风险与注意点

### 3.1 规则/引擎一致性（高优先）
1. **顺子"孔乙己"**：JS 用 `己`，Python `melds.py` 用 `已` → Python 需修正
2. **数字顺子数量**：JS 8 种（含 `乙二三`），Python 7 种缺 `乙二三` → 以 JS 为准修正 Python
3. 若日后用 Python 引擎做自动化测试基准，以上差异会造成判分偏差

### 3.2 运行环境
4. **Python AI 模块依赖路径**：`base.py`/`controller.py` 硬编码插入 `../Phase 1 规则引擎` 路径，但该目录在当前项目树中不存在（core 实际在 `06_调试过程/hua-pai-game-core/`）→ 直接运行会 ImportError，需先调整路径或验证是否仅顶层副本可用
5. **启动脚本用绝对 Python 路径**：`启动游戏.bat` 指向 `C:\Users\Administrator\AppData\Roaming\WPS 灵犀\python-env\python.exe`（Administrator 账户），当前运行账户为 XBW，路径可能失效，需改用 `python` 命令或本机 Python

### 3.3 版本
6. **git 与文件不同步**：`step5-hu.html`（08-06）晚于最后 git 提交（6 月），存在未提交改动风险

### 3.4 规则边界（依据用户沉淀确认）
7. 乙、九绝不可能作为主精
8. 赖子不能当乙九、不能当赖子（只能通配三五七）
9. 碰牌后完全丧失自由度、不参与任何后续操作；限两碰
10. 换扎/穿牌保留原始扎牌记录；泛牌升级不保留记录（玩家有选择权）
