## 4. Python core 包模块职责速查（`06_调试过程/hua-pai-game-core/`）

| 文件 | 主要类/函数 | 职责 |
|------|------------|------|
| `melds.py` | CharType/Color/JingSubType/MeldType/FanType/WinType/Action 枚举、FIXED_SEQUENCES/NUMBER_SEQUENCES/ALL_SEQUENCES | 牌型与顺子常量 |
| `card.py` | Card、create_deck/shuffle_deck/deal/sort_cards | 单牌与牌组（112 张：22 字面×5 + 赖×2） |
| `player.py` | Player | 手牌管理、execute_pen/zhao/zha/chuan/fan/swap_zha、操作判定 |
| `engine.py` | GameState、GameEngine | 主控状态机：start_round/zha_phase/判胡/出牌/响应/结算 |
| `analyzer.py` | _find_triplets/_find_sequences/_enum_melds、check_ting | 听牌检测与牌型枚举 |
| `scoring.py` | calc_sequence_score/calc_pair_hu/.../find_best_zhu_jing | 胡数计算（公式法） |
