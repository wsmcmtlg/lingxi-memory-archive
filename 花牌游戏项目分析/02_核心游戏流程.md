# 02 核心游戏流程（JS 版 step5-hu.html）

> 本文件分析主游戏文件 `step5-hu.html` 的状态机与关键流程，行号以当前文件为准。

## 1. 全局状态对象 `G`（约 L2090）

```javascript
const G = {
  round: 0,             // 当前回合
  currentPlayer: 0,     // 0=庄家(玩家), 1=下家, 2=上家
  phase: 'play',        // 游戏阶段
  deck: [],             // 牌堆
  deckCount: 0,         // 余牌数
  locked: false,        // 锁定（是否可交互）
  drawnCard: null,      // 摸到的暂存牌
  drawnEl: null,        // 暂存牌 DOM
  lastPlayedChar: null, // 最后一次打出的字面
  lastPlayedFrom: -1,   // 最后一次出牌者
  gameOver: false,
  aiLevel: 3            // 0菜鸟 1高手 2大师 3老千
}
```

## 2. 一局完整生命周期

```
initGame() ──发牌──→ [反向扎牌?] ──庄家天胡判定──→ 庄家出牌
  → 旁家响应判定（胡/招/碰/吃/过）
  → 摸牌 → 判定胡/扎/穿 → 出牌 → 循环
  → 胡牌 或 余牌池空(黄庄) → 结算 → 再来一局
```

### 2.1 发牌 `initGame()`（L2395）
- `generateDeck()` 生成 112 张：22 字面各 5 + 赖子 2（Fisher-Yates 洗牌）
- 庄家 26 张，上下家各 25 张
- `rearrangeHand()` 自动排序，设置 `G.currentPlayer=0`
- 重置记牌/碰牌/操作状态

### 2.2 出牌 `playCard()`（L2701）
- 玩家拖拽/点击出牌，或 AI 自动出牌（`aiPickDiscard` → `opponentAutoPlay`）
- 出牌后 `checkOpponentResponse()` 检测旁家响应

### 2.3 旁家响应 `checkOpponentResponse()`（L2834）—— 优先级链

```
第1遍（碰/泛/招检查，按 pi=1,2 顺序）:
  旁家手中有 ≥2 张同字 + 已有该字扎牌 → 泛牌(opponentFan)   [扎牌+旁家出同字→泛]
  旁家手中有 ≥2 张同字 + 碰牌次数 <2（限两碰） + _aiDecidePen 通过 → 碰牌(opponentPen)
第2遍（Phase 6 吃牌，听牌专用）:
  _aiCheckOpponentChi(pi, ch) 通过 → 吃牌(opponentChi)
否则:
  passToNext(from) → 轮到下一家
```

### 2.4 旁家出牌后的庄家响应 `checkResponseAfterOpponent()`（L2890）
- 检测庄家是否可胡/招/碰，控制按钮显隐（胡>招>碰 优先级）

### 2.5 摸牌与自摸判定
- `animateDealerDraw()`（L4780）：动画摸牌
- `checkDealerSelfHu()`（L6016）：庄家自摸判定
- `dealerCheckChuan(ch, isWildZha)`（L4108）：扎牌后摸到同字 → 穿牌升级

### 2.6 扩展牌型操作

| 操作 | 触发 | 关键函数 |
|------|------|---------|
| 碰牌（pen） | 旁家出牌、庄家手有2张 | `opponentPen`(L3030) / `dealerPen`(L3291) |
| 招牌（zhao） | 已有坎牌+旁家打出同字（明杠） | `opponentZhao`(L3070) / `dealerZhao`(L3357) |
| 扎牌（zha） | 手中有4张同字（暗杠） | `dealerZha`(L3970) / `checkDealerZhaAndHu`(L3587) |
| 穿牌（chuan） | 扎牌后摸到同字或赖子通配 → 5张 | `dealerChuan`(L4233) / `dealerCheckChuan`(L4108) |
| 泛牌（fan） | 扎牌+旁家出同字 / 招牌+摸到同字 → 5张 | `opponentFan`(L3208) / `dealerFan`(L3434) |
| 换扎（swap_zha） | 新扎牌机会置换原扎牌 | `showHuanZhaDialog`(L3811) / `doHuanZha`(L3884) |

### 2.7 胡牌
- 庄家自摸：`checkDealerSelfHu()` → `dealerHu()`（L6044）
- 旁家捉统：`checkOpponentHuWithCard(playerIdx, extraChar)`（L6108）
- 庄家捉旁家统：`checkResponseAfterOpponent` 流程内
- 胡牌后 `highlightWinCards()` 高亮，`showSettlePanel()`（L6307）结算

### 2.8 结算 `showSettlePanel()` + `calcScoreDetail()`（L5887）
- 胡数分档：`_huTier(hu)` = floor((hu-17)/5)，17-21 胡=0 档
- 得分：
  - 基础（calcPoints）：`3 + tier`（17-21=3 分，每多 5 胡 +1）
  - 完整奖惩（calcScoreDetail）：未放统旁家每人 `-(2+tier)`；放统旁家 `-(3+tier)`；捉统赢家 `+(5+tier*2)`；自摸赢家 `+(6+tier*2)`

## 4. 记牌基础设施（Phase 1，L2136 起）

| 函数 | 行号 | 职责 |
|------|------|------|
| `G_CARD_TOTALS` | L2136 | 22 字面各 5 + 赖 2 |
| `trackCardUsed(ch, src)` | L2168 | 只在**摸牌**时记录（从余牌取出），出牌/碰/扎不重复记录 |
| `getRemainingCount(ch)` | L2173 | 外部剩余 = 总数 − 已使用 − 庄家手牌中（含花牌反向映射） |
| `trackDeal(h0,h1,h2)` | L2191 | 发牌记录 |
| `analyzeOpponentMelds(pi)` | L2198 | 分析旁家明牌区 |
| `guessOpponentTing(pi)` | L2220 | 推测旁家听牌方向 |
| `isDangerousCard(ch)` | L2270 | 危险牌布尔判断 |
| `getDangerScore(ch)` | L2288 | 0~1 连续危险度 |

> 记牌核心原则（记忆沉淀）：只在摸牌点 `trackCardUsed`；旁家牌数 = 总数 − 余牌 − 庄家手中。
