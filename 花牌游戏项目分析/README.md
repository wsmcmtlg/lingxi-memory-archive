## 一、项目一句话概述

这是一个**单文件前端 PWA 卡牌游戏**，完整实现"湖北公安花牌"三人对战规则（庄家=玩家，上下家=AI），支持人机对战、AI 分级（菜鸟→老千）、方言语音、离线缓存。核心逻辑集中在 `step5-hu.html`（约 8517 行），同时项目内保留了一份**Python 规则引擎 + AI 模块**（开发过程成果目录），形成"JS 前端主产品 + Python 引擎备份/测试"的双轨结构。

## 四、分析结论摘要

1. **游戏规则已高度定型**：规则确认文档 V2、架构文档 v2.1（全部规则已确认）、精牌胡数速查表 V3.0（两次实战验证）均已落档，前后端计胡逻辑均已按查表法实现。
2. **JS 版是"真身"**：所有后续调试应以 `step5-hu.html` 为准；Python 引擎是早期/平行实现，二者存在**已知差异**（见第 5 点），不可混用参考。
3. **AI 已实现四级**：菜鸟(L0)/高手(L1)/大师(L2)/老千(L3)，L3 含记牌、阶段感知、攻防模式、行为识别、吃牌等，并有性能预算（120ms）。
4. **PWA 离线可用**：service-worker 缓存 v3，manifest 配置完整，可安装桌面/手机端。
5. **⚠️ 已发现 JS 与 Python 引擎差异**（调试时重点核对，详见 `05_调试定位与风险清单.md`）：
   - 顺子"孔乙己"：JS 用 `己`，Python `melds.py` 用 `已`；
   - 数字顺子：JS 有 8 种（含 `乙二三`），Python 仅 7 种（**缺 `乙二三`**）；
   - 其余规则（112 张牌、22 字面、赖子通配三五七等）双轨一致。
