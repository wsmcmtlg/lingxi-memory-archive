# 07_配音包框架

> 需求来源：用户提出"能否将游戏配音换成公安口音或松滋口音"。
> 背景：公安口音、松滋口音为湖北荆州下辖**县级方言**，通用 TTS 与网页 Web Speech API 均不支持生成，只能靠**真人录制音频**。
> 用户选定方案：**先搭建可一键切换的多配音包框架**，当前保持普通话，待用户提供录音后再填入公安/松滋配音包。

## 1. 需求背景

- 目标：让花牌游戏的语音播报（报牌音 + 动作音）支持公安口音 / 松滋口音。
- 现实约束：县级方言无法用 TTS 合成，必须使用真人录音。
- 落地路径：先建好"多套音色可一键切换"的架构与开关，录音到位后把音频填入对应配音包即可生效，无需再改逻辑。

## 2. 当前配音机制（改动前）

- 所有配音为**内嵌 base64 音频**，非外部文件加载。
- 数据流：
  - `CFG`（SoundManager IIFE 内 L1927）声明元数据：`v_play_hua:{g:'voice',d:'化'}`、`v_pen:{g:'voice',d:'碰'}` 等，共 **37 个 voice 类型键**（22 张牌报牌音 + 碰/扎/招/吃/穿/泛/胡/自摸/听牌/流局/过/捉统等动作音）。
  - 全部 base64 音频通过 `SoundManager.preload({...})` 一次性预载进 `cache`。
  - `play(name)` 按 `CFG[name]` 判断 `sfx` / `voice` 类型与开关，播放 `cache[name]` 的 `Audio`。
- 当前配音语言：**普通话**（单字报牌音，如"化、千、孔…"）。

## 3. 多配音包框架设计（改动后）

在 SoundManager IIFE 内新增配音包容器与切换接口：

```js
const voicePacks = { mandarin:{}, gongan:{}, songzi:{} };  // 普通话内置；公安/松滋预留
let voicePack = 'mandarin';                                  // 当前包
const vpackCache = {};                                       // 当前包覆盖音频缓存
```

- **普通话包 `mandarin` 为空对象**：无需覆盖，播放走基础内嵌音频。
- **公安包 `gongan` / 松滋包 `songzi` 预留**：待填入录音 base64。
- `play(name)` 播放 voice 音时优先查当前包覆盖：

```js
if(cfg.g==='voice' && voicePacks[voicePack] && voicePacks[voicePack][name]){
  let va = vpackCache[name];
  if(!va){ try{ va=new Audio(voicePacks[voicePack][name]); va.preload='auto'; vpackCache[name]=va; }catch(e){ va=null; } }
  if(va){ va.volume=voiceVol; va.currentTime=0; va.play().catch(()=>{}); return; }
}
// 未命中则回退下方基础音频播放
```

- 新增接口：`setVoicePack(p)`、`getVoicePack()`、`getVoicePackCount(p)`。
- 持久化：`localStorage['hp_vpack']`，随 `_save()/loadPrefs()` 保存读取。
- 空包提示：`_syncUI()` 检查当前包配音数量，为 0 时在设置面板显示"该配音包暂无音频，已回退普通话播报"。

## 4. 设置面板 UI

音效设置面板"语音播报"与"音效音量"之间新增"配音包"下拉：

```html
<div class="snd-row">
  <span class="snd-label">配音包</span>
  <select class="snd-select" id="voice-pack" onchange="changeVoicePack(this.value)">
    <option value="mandarin">普通话</option>
    <option value="gongan">公安口音</option>
    <option value="songzi">松滋口音</option>
  </select>
</div>
<div class="snd-row snd-tip" id="voice-pack-tip" style="display:none">该配音包暂无音频，已回退普通话播报。提供录音后即可启用。</div>
```

配套 JS：`changeVoicePack(v)` 调用 `SoundManager.setVoicePack(v)` 并刷新提示。

## 5. 验证记录

- 切换公安口音：`voicePack=gongan`、`voicePacks.gongan` 为 0 项、空包提示正确显示、已持久化。
- 空包回退：公安/松滋空包下 `play('v_play_hua')` 无异常，走基础普通话。
- 覆盖命中（临时占位实测，验证后已移除）：往 `gongan` 填入真实音频后播放命中覆盖分支（`hit=override`），普通话包命中基础分支（`hit=base`）——证明**填入录音后切换即真正生效**。
- 回归：`hu_tests/run_all.sh` 9 个脚本全部通过，AI 风险/止损/喂牌等逻辑未受影响。

## 6. 后续添加录音步骤（供将来使用）

1. 用户提供公安/松滋口音的录音（每张牌 + 动作音，约 30 段，mp3/wav 均可）。
2. 将每段音频转为 base64 data URI（格式 `data:audio/mpeg;base64,<base64>`）。
3. 打开 `step5-hu.html`，在 SoundManager IIFE 内把 base64 填入对应包对象，键名沿用 CFG 中的 voice 键（如 `v_play_hua`、`v_pen`）。
   ```js
   gongan:{ 'v_play_hua':'data:audio/mpeg;base64,....', 'v_pen':'data:audio/mpeg;base64,....' , ...}
   ```
4. 刷新页面，设置面板切到"公安口音"即可播放；空包提示自动消失。
5. 建议录音文件先放 `sounds/` 目录留档（命名 `v_play_*_gongan.mp3` 等）。
