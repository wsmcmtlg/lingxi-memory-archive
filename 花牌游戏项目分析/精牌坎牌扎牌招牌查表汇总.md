# 精牌坎牌 / 扎牌 / 招牌查表汇总

> 来源：`精牌胡数速查表V3反馈版.docx`、`计分引擎v3.py`、`step5-hu.html`（三方一致，已由 `test_hu_tables_complete.js` 39 项全量验证）

## 一、适用范围与规则

| 项目 | 说明 |
|------|------|
| 坎牌 | 3 张同字（手中暗牌，可灵活调整） |
| 扎牌 / 招牌 | 4 张同字（扎牌=暗杠、招牌=明杠，**共用一张表**，胡数相同） |
| 主精规律 | 主精 = 非主精 × 2（**仅红精**；黑精乙/九不能当主精，恒按非主精计胡） |
| 物理约束 | 每种精牌最多 3皮 + 2花；赖子全局最多 2 张 |
| 赖子规则 | 赖子只能通配三/五/七（红精），**不能**配乙/九（黑精） |
| 黑精 | 黑精（乙/九）无赖子组合，必须纯物理牌 |

## 五、黑精（乙/九）扎牌 / 招牌 — 2 种组合

> 黑精（乙/九）**不能作为主精**（游戏规则限制），故黑精坎/扎/招牌恒按非主精计胡，无主精翻倍。

| 扎牌 / 招牌（4张） | 4 | 2 |
